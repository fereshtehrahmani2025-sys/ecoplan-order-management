# Order Management System

A Java-based Order Management System developed as a learning project to practice Object-Oriented Programming (OOP), Git, and GitHub.

## Features

- Create customer objects
- Create product objects
- Create orders associated with customers and products
- Store multiple orders using ArrayList
- Display order information
- Track development changes using Git

## Technologies

- Java 21
- Object-Oriented Programming (OOP)
- Java Collections (ArrayList)
- Git and GitHub
- IntelliJ IDEA

## Project Structure

- Customer.java - Customer information
- Product.java - Product information
- Order.java - Order details
- Main.java - Application entry point

## How to Run

1. Install Java JDK 21.
2. Clone this repository.
3. Open the project in IntelliJ IDEA.
4. Run Main.java.
